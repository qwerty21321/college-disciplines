# Практическое задание 1

Тестирование программы «Учёт товаров на складе».

Отчёт: [Практическое_задание_1.docx](Практическое_задание_1.docx). Для чтения прямо на GitHub: [Практическое_задание_1.md](Практическое_задание_1.md).

В отчёте 20 проверок и 5 ошибок. Проверка проводилась по коду и отдельным функциям, без открытия графического окна. Код исходной программы не исправлен.

Источник программы: https://github.com/AlexSkoruk/App_testing-warehouse_manager

Версия: ae9da8a81567573c8bec1ff7f6460d7608584af8.

## Запуск программы

Установить Python с Tkinter. Открыть терминал в этой папке и выполнить:

```bash
python main.py
```

На Windows также можно использовать `py main.py`.

## Повторная проверка

```bash
python проверка.py
```

Скрипт проверяет функции и обработчики на отдельном наборе данных. Для каждой проверки создаётся временная папка. Исходный `data.json` не меняется.

Результаты записываются в `Результаты_проверок.json`. Ожидается 15 Pass и 5 Fail. Здесь Fail означает подтверждённую ошибку исходной программы.
