# Практическое задание 1

## Тестирование программы учёта товаров на складе

Приложение: «Учёт товаров на складе».

Цель работы — проверить основные функции программы, найти ошибки и записать результаты.

Программу взял из репозитория, указанного в задании: https://github.com/AlexSkoruk/App_testing-warehouse_manager. Проверялась версия ae9da8a.

Проверка выполнена по коду и отдельным функциям с помощью скрипта. Поля ввода и таблицы заменены тестовыми объектами. Графическое окно не запускалось. Код самой программы не исправлялся.

Для проверок использовал отдельный набор из трёх товаров. Каждая проверка выполнялась отдельно, чтобы предыдущие изменения не мешали результату.

Провёл 20 проверок: 15 прошли успешно, в 5 результат не совпал с ожидаемым. В отчёт включены пять ошибок. Добавление правильных данных, поиск по части названия, фильтр категории, статистика и обычное сохранение работают в проверенных случаях. Скорость работы окна и его внешний вид не проверялись.
