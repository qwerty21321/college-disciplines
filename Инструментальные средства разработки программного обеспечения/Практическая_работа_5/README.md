## Запуск
```bash
python task_manager.py
python -m unittest -v test_task_manager.py
```
Для программы и тестов достаточно Python 3, сторонние библиотеки не нужны. Задачи хранятся в памяти до выхода из программы. Все 9 тестов пройдены.
Исправлены пропуск последней задачи, обращение по индексу вместо ID, удаление элементов во время перебора и обработка неверного ввода в пунктах 3 и 4. Добавлены logging.info/logging.error, уникальные ID и проверка названия из пробелов.
